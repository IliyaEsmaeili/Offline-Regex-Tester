# 🔍 Standalone Regex Tester

A highly capable, dark-themed Regular Expression (Regex) tester built as a single, standalone HTML file. 

This project was specifically designed to work perfectly on **restricted networks and intranets (such as Iran's National Internet / INTR)**. It requires zero external dependencies, no CDNs, and no API calls to function. You can just download it and run it completely offline.

Generated using prompt engineering with **Google Gemini**.

## ✨ Features

- **100% Offline & Standalone:** No external CSS or JS files. Works smoothly on any restricted internet connection.
- **Live Tester & Highlighting:** See your matches instantly as you type.
- **Multiple Test Cases:** Add and manage multiple independent text boxes to test your pattern against different scenarios simultaneously.
- **Capture Groups Visualization:** Automatically extracts and color-codes regex groups in a dedicated side panel.
- **Code Snippet Generator:** Instantly generates and copies the equivalent regex code for JavaScript, Python, PHP, Java, and C# etc.
- **Built-in Cheatsheet:** A comprehensive regex reference guide included at the bottom of the page.
- **Modern Dark Mode:** Eye-friendly UI designed with pure CSS.

## 🚀 How to Use

1. Clone this repository or simply download the `index.html` file.
2. Double-click the `index.html` file to open it in any modern web browser (Chrome, Firefox, Edge, Safari).
3. Type your regex pattern and test texts.
